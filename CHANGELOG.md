# Changelog

## v0.1.0 — Initial Release (2026-10-18)

### Added
- Real-time audio capture and live speech transcription using Faster-Whisper
- Transcript text selection, copying, and editing
- Manual transcript correction with Save Changes support
- Session history with SQLite persistence
- Vocabulary management (save, search, delete words/phrases)
- Dark-themed PySide6 UI
- Windows single-file executable build (PyInstaller)
- Windows installer (Inno Setup)
